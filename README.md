# Homebrew Tap

This tap publishes Homebrew formulas for tools released from the `alvaroum` GitHub account.

## Install Fluid Transcription

```bash
brew tap alvaroum/fluid-transcription
brew install fluid-transcription
```

The formula currently installs the Apple Silicon macOS release artifact from the app-specific tap and exposes:

- `ft` as the preferred command
- `fluid-transcription` as a compatibility alias

Release source:

```text
https://github.com/alvaroum/fluid-transcription/releases
```
